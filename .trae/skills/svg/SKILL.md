# SVG 图标设计技能 (SVG Icon Designer)

## 功能概述

本技能能够理解用户对图标的自然语言描述（形状、颜色、风格、尺寸等），并生成可直接使用的 SVG 代码。支持以下功能：

- **文字描述 → SVG 代码**：例如"一个红色警告三角形，内部有感叹号，线性风格"
- **风格定制**：支持线性（outline）、填充（filled）、双色（duotone）、圆角/直角
- **尺寸控制**：默认 24×24，可指定任意尺寸
- **即时预览**：在 IDE 内或浏览器中预览图标效果
- **一键插入/保存**：将生成的 SVG 插入当前编辑器光标位置，或保存为 `.svg` 文件

## 使用方法

### 1. 触发技能

在 IDE 的 AI 对话面板中输入以下任意触发短语：

- `@svg 画一个蓝色的云朵图标，填充风格`
- `绘制图标：一个带有数字 3 的红色铃铛`
- `生成 SVG：一个房子的轮廓，烟囱冒烟`

也可以直接使用命令（若 IDE 支持）：

- `/svg 一个绿色的对勾`

### 2. 参数选项（可选）

你可以通过后缀形式提供额外参数：

- `[size=48]` → 设定 viewBox 0 0 48 48
- `[color=#FF5733]` → 指定主色
- `[style=outline]` → 仅轮廓 (stroke)，无填充
- `[style=filled]` → 实体填充
- `[rounded]` → 圆角风格（如适用）

示例：
> 绘制一个放大镜图标，蓝色 [color=#1E88E5] [size=32] [style=outline]

### 3. 输出处理

生成 SVG 代码后，技能会询问你：

- **预览**：在新标签页中显示图标实际样子
- **插入**：将 SVG 代码插入当前打开文件的光标位置
- **保存**：弹出保存对话框，存储为 `.svg` 文件

## 实现细节（供 IDE 调用）

### 输入格式

技能接收一个 JSON 对象：

```json
{
  "description": "一个绿色树叶形状的心脏，填充风格",
  "size": 24,
  "color": "#2e7d32",
  "style": "filled",
  "rounded": false
}
```

### 输出格式

返回包含 SVG 代码和元数据的 JSON：

```json
{
  "svg": "<svg ...>...</svg>",
  "viewBox": "0 0 24 24",
  "width": 24,
  "height": 24,
  "description": "绿色树叶心脏"
}
```

### AI 生成提示词模板

```
你是一个专业的 SVG 图标设计师。根据以下要求生成图标代码：

- 描述：{{description}}
- 尺寸：{{size}}x{{size}}，viewBox="0 0 {{size}} {{size}}"
- 主色：{{color}}（如果存在）
- 风格：{{style}}（outline 表示使用 stroke 和 fill="none"；filled 表示使用 fill，无 stroke）
- 额外属性：{{rounded ? 'stroke-linejoin="round" stroke-linecap="round"' : ''}}

要求：
1. 只返回 SVG 代码，不要任何额外解释。
2. 使用语义化路径，确保图标可缩放。
3. 若风格为 outline，请设置 stroke-width="2"。
4. 包含 xmlns="http://www.w3.org/2000/svg"。
5. 确保输出是有效的 XML。
```

## 示例对话

**用户**：  
> 绘制一个红色的警告三角形，内部有黑色感叹号，填充风格，尺寸 48

**技能输出**：  
```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 48 48" width="48" height="48">
  <path fill="#FF0000" d="M24 4L2 44h44L24 4z" />
  <circle cx="24" cy="32" r="2.5" fill="#000000" />
  <rect x="22" y="18" width="4" height="10" fill="#000000" />
</svg>
```
（然后弹出预览/插入/保存选项）

## 注意事项

- 生成的 SVG 不包含外部依赖或脚本，可安全使用。
- 如果描述过于复杂或包含不安全元素（如动画），技能将要求用户简化描述。
- 颜色支持 CSS 颜色名、十六进制、RGB 等标准格式。
- 如果未指定颜色，默认使用 `currentColor`（以便继承父元素颜色）。

## 扩展支持

- **批量生成**：提供 JSON 数组描述，一次性生成多个图标。
- **手绘转 SVG**：上传手绘草图（Base64），AI 识别并生成 SVG（需要额外的视觉模型支持）。
- **无障碍属性**：自动添加 `<title>` 和 `<desc>` 标签。

## 故障排除

| 问题               | 可能原因                       | 解决方案                                        |
| ------------------ | ------------------------------ | ----------------------------------------------- |
| 生成的图标路径错误 | AI 生成了无效的路径数据        | 重新描述，更简单具体，例如"一个矩形 + 一个圆形" |
| 颜色不生效         | 忘记写 `fill` 或 `stroke` 属性 | 在描述中强调"填充红色"或"描边蓝色"              |
| 图标太大/太小      | viewBox 与实际路径不匹配       | 指定尺寸参数，如 [size=32]                      |
| 预览无法显示       | IDE 限制了 Webview             | 使用"保存"后通过系统 SVG 查看器打开             |
